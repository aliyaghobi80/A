# Markazi System Checker

نرم‌افزار ویندوزی بخش فنی «کامپیوتر مرکزی» برای بررسی مشخصات و سریال قطعات،
کنترل کیفیت (QC)، تست‌های تشخیصی قطعات سخت‌افزاری، نصب آفلاین نرم‌افزارها و نصب ترتیبی درایورها است.
رابط کاربری با Flutter/GetX و سرویس محلی جمع‌آوری و استقرار با Python پیاده‌سازی شده است.

**نسخه انتشار**: 1.1.45 (Build 1.1.45+46)  
**نسخه قرارداد رابط (API Contract)**: 5

---

## قابلیت‌های اصلی

- **شناسایی و مشخصات سخت‌افزار**: نمایش دقیق قطعات سخت‌افزاری (CPU، مادربرد، مدل/SKU لپ‌تاپ، گرافیک‌های مجتمع و مجزا، حافظه‌های RAM، دیسک‌های فیزیکی و پارتیشن‌ها، باتری و درایوهای USB).
- **نوار عنوان اختصاصی داخل برنامه (Custom In-App Title Bar)**: یکپارچه‌سازی نوار عنوان مدرن با استفاده از `window_manager`، سازگار با تم تیره/روشن و چیدمان راست‌به‌چپ (RTL)، قابلیت جابجایی پنجره، دابل‌کلیک برای بیشینه‌سازی، منوی Snap Layouts ویندوز ۱۱ و پنهان‌سازی خودکار در حالت تمام‌صفحه.
- **تست‌های تشخیصی پیشرفته سخت‌افزار (Modernized Hardware Diagnostics)**:
  - **تست مانیتور و پیکسل**: تمام‌صفحه بازی (Game Fullscreen) با پوشش کامل تسک‌بار و نوار عنوان، رنگ‌های کاملاً ثابت و خالص بدون انیمیشن، گرادیان یا متن، پنهان‌سازی اشاره‌گر ماوس، هدایت با کلیدهای جهت‌نما و بازگردانی دقیق موقعیت و مقیاس DPI پنجره پس از خروج.
  - **تست کیبورد**: چیدمان ریسپانسیو هماهنگ با عرض صفحه، تفکیک کلیدهای فیزیکی (Shift/Ctrl/Alt چپ و راست، بخش Numpad و کلیدهای سیستمی)، راهنمای کلیدهای تسخیرشده توسط ویندوز و شمارنده ضربات کلیدها.
  - **تست صدا و هدفون**: تولید مستقل موج صوتی WAV در حافظه (فرکانس ۴۴۰ هرتز، ۱ کیلوهرتز، سوئیپ فرکانسی بم و نویز صورتی) بدون فایل خارجی یا لایسنس، تست تفکیک کانال چپ، راست و هر دو، اسلایدر ولوم و هشدار قطع بودن صدا.
  - **تست میکروفون**: نمایشگر زنده دامنه صدا (Level Meter)، ضبط و پخش آزمایشی با پاک‌سازی خودکار فایل موقت و میانبر دسترسی حریم خصوصی ویندوز (`ms-settings:privacy-microphone`).
  - **تست وب‌کم**: پیش‌نمایش زنده تصویر درون برنامه با `camera_windows` بدون نیاز به برنامه دوربین ویندوز، انتخاب دوربین، معکوس‌سازی تصویر، ثبت تصویر نمونه و بررسی دسترسی.
  - **تست ماوس**: تشخیص نگه داشتن دکمه‌ها (کلیک چپ، راست، وسط و دکمه‌های کناری)، نشانگر تعقیب حرکت ماوس، تشخیص دابل‌کلیک، ردیابی اسکرول و مهار منوی راست‌کلیک.
  - **حذف کارنامه تست**: حذف کامل بخش زائد کارنامه و ثبت دستی نتایج، با حفظ دکمه مستقل گزارش QC در بالای صفحه.
- **مدیریت وضعیت پایدار (InstallStateService)**: سرویس سینگلتون دائمی GetX برای جلوگیری از پرش یا ناپدید شدن وضعیت «در حال نصب»، با شناسه ترتیبی صعودی `state_revision`، زمان دقیق سرور `server_time`، سیستم نظرسنجی تطبیقی تک‌حلقه‌ای، پایداری وضعیت هنگام قطعی لحظه‌ای شبکه و همگام‌سازی خودکار کارهای متوقف‌شده (`interrupted`) پس از راه‌اندازی مجدد بک‌اند.
- **موتور استقرار هوشمند درایورها (Driver Deployment Engine)**:
  - پشتیبانی از حالت موازی 2X برای نصاب‌های مستقل و امن EXE (صدا، شبکه کابلی، وای‌فای، بلوتوث، تاچ‌پد، کارت‌خوان و ...).
  - موانع ترتیبی سخت‌گیرانه (Strict Barriers) برای قطعات حیاتی (چیپست، MEI، ذخیره‌سازی، گرافیک، MSI، رانتایم‌ها).
  - بررسی Mutex سیستمی `Global_MSIExecute` و مدیریت خطای 1618 با حداکثر ۲ بار Retry تصاعدی و بازگشت خودکار به صف سریال.
  - رعایت اولویت توپولوژیکی کارت گرافیک (iGPU قبل از dGPU)، ادغام Adrenalin برای پردازنده‌های APU و وقفه پایدارسازی نمایشگر (Display Settle Delay) به مدت ۵ تا ۸ ثانیه.
  - ریکاوری نیتیو رابط کاربری هنگام ریست درایور گرافیک با حفظ نشست فعال بک‌اند و اولویت آداپتور کم‌مصرف.
- **اسکنر و صف بهینه‌شده نرم‌افزارها (Software Queue Optimization)**:
  - چینش بسته‌ها بر اساس وزن بسته (ابزارهای سبک مانند WinRAR, Firefox, VLC, KMPlayer, FDM ابتدا؛ رانتایم‌های VC++ و .NET قبل از برنامه‌های وابسته؛ برنامه‌های سنگین و آفیس به عنوان آخرین مانع ترتیبی).
  - رفع هم‌پوشانی و عدم استخراج تکراری پوشه بازشده در کنار فایل آرشیو `.rar` هم‌نام.
  - لیست سفید آفیس: اجرای انحصاری `Setup_Office 2024.cmd` با نظارت ۶۰۰ ثانیه‌ای و ممانعت از نصب آفیس روی ویندوزهای ویرایش Home.
  - خروج خودکار نرم‌افزار Windows Update Blocker از صف دسته‌ای و نادیده گرفتن پوشه‌های حاوی عبارت «آموزش».
  - سیاست صفر سوییچ حدسی برای نصاب‌های ناشناخته و اجرای امن از طریق خلبان خودکار گرافیکی (GUI Autopilot).
- **پایداری داده‌ها و ایمنی فرآیندها**: ذخیره‌سازی اتمیک وضعیت صف در `%LOCALAPPDATA%\MarkaziSystemChecker\driver_queue_state.json` و `software_queue_state.json`، قطع تمیز درخت فرآیندهای معلق با `taskkill /F /T` و سرکوب کامل ریستارت‌های ناخواسته سیستم.

## ساختار پروژه

```text
backend/              سرویس محلی، جمع‌آوری اطلاعات و موتورهای نصب
frontend/             رابط Flutter، GetX، ویجت‌ها و تست‌ها
config/               تنظیمات پوشه‌ها، نیازمندی‌ها و چک‌لیست‌ها
docs/                 مستندات معماری و گزارش‌های اعتبارسنجی
installer/            پروژه ساخت فایل نصبی Inno Setup
build_production.py   اسکریپت ساخت کامل بسته‌های پرتابل و نصاب
PROJECT.md            نقشه راه، نیازمندی‌ها، موجودی قابلیت‌ها و ساختار کد
CONTRACT.md           مشخصات فنی و قرارداد پایدار API (نسخه ۵)
AGENTS.md             قوانین مهندسی، معماری و الزامات استقرار
```

## راهنمای اجرا از سورس

### ۱. اجرای سرویس بک‌اند
```powershell
py -3 backend/main.py
```

### ۲. اجرای رابط کاربری فلاتر
```powershell
cd frontend
flutter pub get
flutter run -d windows
```

---

## بررسی‌های کیفی و تست‌ها

پیش از انتشار، کلیه بررسی‌ها باید بدون خطا پاس شوند:

```powershell
py -3 -m unittest discover -s backend/tests -p "test_*.py"
cd frontend
flutter analyze
flutter test
```

> **اصل ایمنی تست‌ها**: هیچ تستی مجاز به نصب واقعی پکیج، فعال‌سازی لایسنس، دستکاری سرویس‌های ویندوز، تغییر تنظیمات پاور یا ریستارت سیستم نیست و تست‌ها از محیط‌های Mock استفاده می‌کنند.

## ساخت بسته انتشار (Production Build)

برای تولید نسخه نهایی شامل پوشه پرتابل، فایل ZIP و نصاب رسمی Inno Setup:

```powershell
py -3 build_production.py
```

خروجی‌ها در دایرکتوری `dist/` ساخته می‌شوند. نصاب و برنامه به هیچ وجه سیستم را به صورت خودکار راه‌اندازی مجدد نمی‌کنند؛ پس از اتمام کارها، یادآوری ریستارت دستی به تکنسین نمایش داده می‌شود.
