# Markazi System Checker

نرم‌افزار ویندوزی بخش فنی «کامپیوتر مرکزی» برای بررسی مشخصات و سریال قطعات،
کنترل QC، نصب آفلاین نرم‌افزارها و نصب ترتیبی درایورها است. رابط کاربری با
Flutter/GetX و سرویس محلی جمع‌آوری و نصب با Python ساخته شده است.

## قابلیت‌های اصلی

- نمایش CPU، مادربرد، مدل/SKU لپ‌تاپ، GPUهای مجتمع و مجزا، دیسک‌ها و USBها.
- نمایش اسلات‌های پر و خالی RAM و اطلاعات قابل دریافت از SMBIOS.
- اسکن بازگشتی نرم‌افزارهای EXE/MSI و به‌روزرسانی لحظه‌ای وضعیت نصب.
- اسکن پوشه درایور، استخراج آرشیوها و نصب ترتیبی همه بسته‌های شناسایی‌شده.
- پشتیبانی از نصاب‌های مستقل متعدد در یک پوشه و درخت کامل INF با PnPUtil.
- تنظیمات تحویل دستگاه، گزارش QC و ابزار محاسبات با ورودی عددی LTR.
- شروع برنامه بر اساس آماده‌شدن واقعی بک‌اند و اطلاعات اولیه، بدون مکث ثابت.
- تم روشن/تیره و رابط فارسی RTL با نمایش صحیح اعداد، سریال‌ها و مسیرها.

## ساختار پروژه

```text
backend/              سرویس محلی، جمع‌آوری اطلاعات و موتورهای نصب
frontend/             رابط Flutter، GetX و تست‌های ویجت
config/               تنظیمات پوشه‌ها و چک‌لیست‌ها
docs/                 مستندات و گزارش اعتبارسنجی نسخه‌ها
installer/            پروژه Inno Setup
build_production.py   ساخت خروجی کامل انتشار
```

جزئیات قواعد توسعه و ایمنی در [AGENTS.md](AGENTS.md) ثبت شده است.

## اجرا از سورس

```powershell
py -3 backend/main.py
cd frontend
flutter run -d windows
```

## تست

```powershell
py -3 -m unittest discover -s backend/tests -p "test_*.py"
cd frontend
flutter analyze
flutter test
```

تست‌ها نصب واقعی یا تغییر تنظیمات سیستم انجام نمی‌دهند.

## ساخت انتشار

```powershell
py -3 build_production.py
```

خروجی‌ها در `dist/` ساخته می‌شوند: پوشه پرتابل، ZIP نسخه‌دار و فایل نصب
Inno Setup. برنامه و نصاب هیچ‌وقت سیستم را به‌صورت خودکار ری‌استارت نمی‌کنند؛
پس از پایان نصب‌ها، یادآوری ری‌استارت دستی نمایش داده می‌شود.
