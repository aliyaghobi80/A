# گزارش اعتبارسنجی نسخه 1.1.33

تاریخ ساخت نهایی: ۱۴۰۵/۰۷/۰۶ (2026-09-28)

## مسیر استخراج و اجرای KMS

- نام‌های `kms`، `kms v6`، `KMS v6`، `KMS V6` و گونه‌های دارای فاصله،
  خط تیره یا زیرخط بدون حساسیت به بزرگی حروف شناسایی می‌شوند. جست‌وجو در
  زیرپوشه‌های محدود و بدون دنبال‌کردن symlink/junction انجام می‌شود.
- آرشیو KMS در پوشه‌ای ایزوله کنار همان آرشیو استخراج می‌شود و موفقیت فقط
  وقتی ثبت می‌شود که فایل معتبر `WINDOWS.cmd` واقعاً در محتوای استخراج‌شده
  پیدا شود. پوشه یا فایل موجود کاربر بازنویسی یا حذف نمی‌شود.
- برای آرشیو RAR، وجود WinRAR/UnRAR یا 7-Zip معتبر بررسی می‌شود. `tar.exe`
  ویندوز به‌تنهایی پیش‌نیاز قابل‌اعتماد RAR محسوب نمی‌شود. اگر ابزار موجود
  نباشد، نصاب معتبر WinRAR از همان پوشهٔ نرم‌افزارها به‌صورت silent نصب و
  سپس استخراج ادامه داده می‌شود.
- در صف نصب کامل، WinRAR انتخاب‌شده قبل از مراحل استخراج Office/KMS قرار
  می‌گیرد و فقط یک‌بار اجرا می‌شود. اگر در صف انتخاب نشده باشد، مرحلهٔ KMS
  برای آرشیو RAR آن را به‌عنوان پیش‌نیاز پیدا و نصب می‌کند.
- اجرای CMD با ورودی قطعی `1` و یک کلید از پیش صف‌شده برای پایان
  `Press any key` انجام می‌شود. برنامه تا خروج پردازش متعلق به همان CMD صبر
  می‌کند، پردازش زمان‌گذشته را می‌بندد و سپس وضعیت رسمی لایسنس را چند بار
  دوباره بررسی می‌کند.
- مهلت اجرای فعال‌سازی backend به ۳۰۰ ثانیه و مهلت درخواست رابط به ۶ دقیقه
  افزایش یافت تا عملیات قانونی روی سیستم‌های کند به خطای زودهنگام نخورد.

## محافظ Windows Home و سیستم فعال

- Windows 10/11 Home در لایه‌های صف، orchestrator و runner قبل از هر جست‌وجو،
  استخراج، نصب پیش‌نیاز یا اجرای CMD متوقف می‌شود؛ فقط سیاست Windows Home
  اورجینال و میانبرهای Office باقی می‌مانند.
- اگر وضعیت تجمیع‌شدهٔ رسمی نشان دهد Windows از قبل فعال است، KMS حتی اسکن یا
  استخراج نمی‌شود و هیچ ابزار فعال‌سازی اجرا نمی‌گردد.
- مسیر CMD استخراج‌شده باید داخل پوشهٔ نرم‌افزارهای انتخاب‌شده باقی بماند؛
  مسیر خارج از آن رد می‌شود.
