# Markazi System Checker 1.1.26

## Summary of Changes

- **Phantom 2GB USB Drive Removal & Real-Time Storage:**
  - Diagnosed and purged the stale disk cache file (`system_info_cache.json`) where a disconnected 2GB USB drive was previously retained.
  - Added background daemon hardware rescan in `backend/api_server.py` on startup to ensure `_cached_data` is immediately overwritten with live hardware values.
  - Added fast dedicated `/api/system/storage` endpoint running in <0.4s to refresh storage without blocking on full system scans.
  - Updated `SystemInfoController` and `ApiService` to fetch real-time storage info with `forceRefresh: true` on initial load.
  - Upgraded Storage UI in `SystemSpecsPage`: internal disks (NVMe, SSD, HDD) and real-time USB flash drives are separated. Connected USB drives display live capacity, usage bars, drive letters, and safe eject buttons. Disconnected drives disappear dynamically.

- **Real-Time Software Package Installation Status & UI/UX Fixes:**
  - Fixed a critical branch priority bug in `simple_mode_view.dart` and `packages_card.dart` where `else if (installAllowed)` was evaluated before `else if (isInstalled)`. Installed packages now immediately show the green "نصب شده" badge, "باز کردن" (Open) button, and "حذف" (Uninstall) button instead of being masked by install buttons.
  - Enhanced `SoftwareController`: `isCurrentInstalling` and `isCurrentQueued` now inspect active batch installation states (`installing`, `queued`, `currentItemName`).
  - Updated `_startBatchStatusPolling` to update `packagesResponse` in-place as soon as each individual package completes installation and trigger UI refreshes reactively without requiring manual rescan clicks.
  - Increased auto-detection polling attempts in `_startAutoDetectionPoll` from 20 (60s) to 80 (200s) with 2.5s intervals for manual installers.
  - Added real-time animated spinners ("در حال نصب...") and queue badges ("در صف نصب") to package rows in `simple_mode_view.dart` and `software_install_page.dart`.

- **Version Bump:**
  - Upgraded release version across `build_production.py`, `backend/api_server.py`, `frontend/pubspec.yaml`, and `installer/setup.iss` to `1.1.26` (build `27`).
