# Markazi System Checker 1.1.18 validation

## Automatic NSIS uninstall

- Inspects the registered uninstaller executable before adding any vendor switch.
- Adds NSIS's case-sensitive `/S` switch only when an NSIS/Nullsoft signature is present.
- Preserves vendor-provided arguments and normalizes a lower-case `/s` token to `/S`.
- Leaves unknown uninstall engines untouched instead of guessing unsafe command-line switches.
- Continues to normalize MSI removal to `/x /passive /norestart REBOOT=ReallySuppress`.

- The command was inspected but not executed, so the workstation's installed KMPlayer was not removed during validation.
