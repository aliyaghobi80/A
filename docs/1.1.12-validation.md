# Markazi System Checker 1.1.12 validation

## Startup Apps

- A dedicated action in Device Important Settings disables entries surfaced by Windows Startup Apps.
- The action preserves the startup commands and writes the reversible disabled state used by Windows Settings/Task Manager.
- `Run`, `Run32`, packaged/existing approved entries, and user/common Startup folders are covered; `RunOnce` is intentionally untouched.
- A confirmation dialog appears before the bulk action and `ms-settings:startupapps` opens afterward for verification.

## Windows 10 Background Apps

- The global Store/UWP background-app setting can be disabled on Windows 10.
- `ms-settings:privacy-backgroundapps` opens after a successful change.
- On Windows 11 the action is disabled in the UI with a platform-specific explanation, and the backend rejects direct calls without making changes.
