# Markazi System Checker 1.1.21

## Installer prerequisites

- Recognize the Visual C++ 2010 checkbox text: "I have read and accept the license terms."
- Follow child/grandchild processes belonging to the launched installer, without granting access by window title alone.
- Keep automation running while prerequisite installer children finish; do not wait indefinitely for installed applications launched from Program Files.
- Existing explicit restart-later handling remains in place. Optional Microsoft installation telemetry is not needed to enable Install and is left unchanged.
- Tests exercise the exact checkbox text, process ownership, prerequisite lifetime, and restart handling. No KMPlayer install/uninstall or driver installation was performed on the host.

## Driver discovery and queue

- Loose opaque EXE/MSI downloads in nested folders become individual packages; preserve recognized setup/INF package layouts.
- Unknown hardware metadata is distinguished from a known mismatch. Vendor installers without extractable IDs remain eligible for the install-all queue.
- Both install-all and select-all include eligible unknown packages; OS/hardware mismatches remain excluded by default.
- Descend into newly extracted directories during the same scan, including nested ZIP/RAR/7z archives.
- RAR extraction uses installed WinRAR/7-Zip, with Windows tar as a fallback. Extraction support still depends on the available tool and archive format; encrypted/corrupt archives are not claimed to be installable.
