# Markazi System Checker 1.1.10 — Validation

## Fixes

- Fixed the application settings navigation regression. Sidebar destination 6 is now accepted by the GetX navigation controller and opens `SettingsPage`.
- Expanded the power action for desktops and laptops.
- One action now sets display-off, sleep, and hibernate timeouts to Never for both AC and DC modes.
- Desktop systems no longer have the action disabled when no battery is present.
- Laptop systems configure both plugged-in and battery values.
- No restart command is issued by this action.

## Verification

- Backend tests: 61 passed.
- Flutter tests: 25 passed.
- Flutter analysis: no issues.
- Power tests mock all six `powercfg` calls; no actual power setting was changed during testing.
- Clean-process packaged smoke test: frontend and bundled backend started; health reported `1.1.10`.
