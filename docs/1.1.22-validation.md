# Markazi System Checker 1.1.22

## Device preparation and QC

- Read Screen, Sleep and Hibernate AC/DC timeouts from the active Windows power scheme. Show verified Never state, not a remembered button click.
- Verify startup registry/folder/packaged-app states after disabling; report partial or unreadable results without a green success state.
- Windows 10 background apps: verify the user setting and global machine policy; Windows 11 control stays disabled. This is not a control for arbitrary desktop background processes.
- Laptop power button sets configured AC mode to Best performance and DC mode to Balanced through documented Windows APIs, then reads both back. Systems without those API exports explicitly report unsupported. Thermal and other system policies can override the effective power mode.
- Refresh device preparation state every ten seconds and after actions. Green cards also have textual status and a checkmark, following UI/UX Pro Max feedback/accessibility guidance.
- QC includes preparation warnings and unknown states; missing Never settings prevent a ready-for-delivery result. Refresh QC after device actions.
- No automatic restart and no host-setting writes during validation.

## RAM and laptop identity

- Match SMBIOS Type 17 slot labels to installed modules by firmware locator/bank, not array order. Preserve empty positions when firmware reports them.
- Display reported memory locations and distinguish empty from unknown. Never infer A1/A2/B1/B2 from ambiguous controller labels; firmware may not expose the physical board map.
- Correct SMBIOS DDR5 and LPDDR4 mappings; show DIMM/SO-DIMM when known.
- CL is displayed only when explicitly present in the module part number; it is rated/part-number CL, not measured active latency. Otherwise show unknown; no SPD kernel driver is installed.
- Read Win32_ComputerSystem.SystemSKUNumber first, then product SKU/BIOS fallbacks. Show System SKU separately from reported model in simple and advanced identity views.

## Validation

- Backend: 91 tests passed, including synthetic two/four-slot firmware, rated CL, SKU precedence, partial action failures, QC readiness, and mocked AC/DC setters.
- Flutter: 31 tests passed, including narrow light/dark state changes and clearing stale green status. Static analysis: no issues.
- Host read-only checks: Windows 11 desktop; all six timeouts were zero, startup entries disabled, AC/DC configured modes Balanced. No laptop or Windows 10 live mutation test was performed.
- Windows 10 behavior and laptop power writes were tested with mocks; physical laptop/Windows 10 acceptance testing remains recommended.
- Packaged backend on isolated port 18091 returned health version 1.1.22, six zero timeouts, startup 0 enabled/61 entries, and PASS for both desktop device-preparation QC checks. Test process stopped afterward.
