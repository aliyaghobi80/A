# Markazi System Checker 1.1.8 — Validation

## Added and corrected

- Live Solar Hijri date and local time in the global application header.
- Firmware-backed RAM slot reporting using both SMBIOS `DeviceLocator` and
  `BankLabel`; no slot name is invented from module order.
- The actual total DIMM count is read from `Win32_PhysicalMemoryArray`.
- Windows 10/11 Home is presented as `ویندوز اورجینال اصلی`; other editions
  show the detected activation state.
- Microsoft Basic Display Adapter produces a prominent graphics-driver warning.
- Select All is a true toggle in both software and driver pages.
- Splash motion uses transform/opacity effects only, keeps the four-second
  startup contract, and honors the operating system's reduced-motion setting.

## Safety

- This change performs only read-only hardware queries during validation.
- No software or driver installation was started.
- Existing restart suppression and Restart Later behavior remain enabled.

## Automated verification

- Flutter static analysis: no issues.
- Flutter tests cover Jalali conversion, Home-edition rules, Basic Display
  Adapter detection, Select All toggling, and splash behavior.
- Backend tests cover common RAM slot formats and explicitly prevent uncertain
  Controller/Channel names from being converted into a guessed motherboard slot.
