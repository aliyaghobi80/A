# Markazi System Checker 1.1.24

## Licensing state and presentation

- Read numeric Windows SoftwareLicensingProduct status even when slmgr returns an edition name or localized text; numeric WMI status takes precedence. Limit Windows queries to the OS ApplicationId and exclude add-on licenses.
- Reconcile the existing external-tool result against actual licensing state with up to six checks. A nonzero process exit does not negate a confirmed active license; exit zero alone is not proof of activation.
- Keep cancellation unchanged. Unconfirmed activation receives a bounded, neutral warning instead of dumping the tool log into a red snackbar. Existing follow-up refreshes remain.
- Home editions disable both external activation actions in the license page and backend; Office must also be installed. Home edition alone is not used to mark the license page ready.
- No activation tool was executed during validation and no activation-script automation was added.

## Desktop and timezone

- Enable This PC, Control Panel and Recycle Bin desktop shell icons with one explicit action; require Windows activation both in UI and backend. Write only those three per-user icon entries and notify Explorer.
- Read icon status back; respect globally hidden desktop icons instead of reporting success unconditionally.
- Display current Windows timezone identifier and automatic-timezone state. One button sets Iran Standard Time with DST disabled, then enables automatic timezone configuration.
- Automatic timezone is location-dependent and can later select a different zone. Location privacy permissions and organization policies are NOT changed; show a Location reminder when needed. This action does not change the separate automatic-clock setting or claim an NTP synchronization.
- GetX refresh clears stale completion states; UI/UX Pro Max guidance informed explicit disabled labels, bounded feedback and verified completion icons.
