# Markazi System Checker 1.1.20 validation

## Compact software actions

- Replaced the crowded filter/deduplication toolbar with three controls: select all, uninstall selected, and automatic install.
- Select all toggles every visible actionable package and shows an indeterminate state for partial selection.
- Selected installed applications can be removed sequentially after one confirmation dialog.
- Automatic install targets selected ready packages, or every ready package when nothing is selected.
- Duplicate installer entries are always hidden; the user no longer needs a separate toggle.
- Controls use 44-pixel minimum targets, clear disabled states, vector Material icons, and responsive wrapping.

## Architecture-aware Windows Update Blocker

- On 64-bit Windows, only `Wub_x64.exe` is exposed.
- On 32-bit Windows, only `Wub.exe` is exposed.
- If the preferred architecture is absent, the available safe fallback remains visible.
- Real-folder scan of `H:\PROGRAM` on this 64-bit system returned one WUB entry: `Wub_x64.exe`.
