# Markazi System Checker 1.1.17 validation

## Resilient uninstall resolver

- Safely matches Windows ARP display-name qualifiers such as KMPlayer's `(remove only)` suffix.
- Uses known product aliases plus publisher and normalized install location to disambiguate matches.
- Rejects partial-name collisions and equal-scoring ambiguous uninstall commands.
- Ignores entries marked as `SystemComponent` or `NoRemove`.
- Opens Windows Installed Apps as a manual fallback instead of running an unrelated setup executable.
- Continues to normalize MSI maintenance commands to `/x /passive /norestart REBOOT=ReallySuppress`.

## Real-machine read-only audit

The installed packages represented in `H:\PROGRAM` resolved as follows without executing any uninstaller:

- Google Chrome -> registered MSI product-code removal.
- KMPlayer 64X -> `KMPlayer 64X (remove only)` -> registered `uninstall.exe`.
- Microsoft Office 2024 (Pro Plus) -> Office Click-to-Run ARP command.
- Mozilla Firefox -> registered `uninstall\helper.exe`.
- VLC media player -> registered `uninstall.exe`, disambiguated by install location.
- WinRAR 7.13 (64-bit) -> registered `uninstall.exe`.
