# Markazi System Checker 1.1.14 validation

## Startup Apps regression fixes

- Replaced nested `Start-Process` elevation with direct Win32 `ShellExecuteExW` execution and process waiting.
- PowerShell errors are captured as clean JSON; CLIXML/progress records are no longer exposed to the UI.
- Win32 Startup entries in HKCU/HKLM `Run`, `Run32`, and Startup folders are disabled through `StartupApproved` without deleting commands.
- Packaged MSIX/UWP/Desktop Bridge StartupTasks in `SystemAppData` are also changed from `Enabled` to `DisabledByUser`.
- Preserved the disabled registry payload as an explicit `System.Byte[]`; this fixes the `SetValue` / `RegistryValueKind` type mismatch reported in 1.1.13.
- The result message reports the number of registry and packaged entries changed.

## Validation

- Temporary HKCU registry write/read test: `REG_BINARY`, 12 bytes, state byte `3`; test key removed in `finally`.
- Backend unit tests: 64 passed.
- Flutter widget/unit tests: 26 passed.
- Flutter static analysis: no issues found.
- Full elevated PowerShell payload: parsed successfully (4,469 characters) without execution.
- Packaged portable smoke test: UI launched and `/api/health` returned version `1.1.14`, phase `4`, API contract `2`.
