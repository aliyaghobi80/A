# Markazi System Checker 1.1.9 — Validation

## Delivered changes

- Circular logo clipping in splash, sidebar, application header, and branding settings.
- Explicit installed Windows 10/11 edition in the license page.
- Automatic Word, Excel, and PowerPoint desktop shortcuts after Office detection/install.
- OEM license-page handling that accepts positive EULA controls without toggling them off again.
- Windows Update Blocker included once at the end of automatic software deployment.
- Windows Home guard: automatic WUB is skipped; manual execution requires an explicit warning confirmation.
- Safe, user-assisted Taskbar pin actions for WUB and Windows Security.
- New **Important Device Settings** page (expanded for desktop/laptop power settings in 1.1.10).
- BIOS, UEFI, EC, and firmware packages excluded from the automatic driver queue to prevent forced restarts.
- Driver and software queues never request or press Restart Now and always remind the technician to restart manually after deployment.

## Safety notes

- Tests did not install software/drivers, disable Windows Update, change power settings, or pin Taskbar items.
- Windows 11 does not provide a supported silent arbitrary-app Taskbar pin API. The app creates a valid Start-menu shortcut, opens the target, and asks the user to complete the final Taskbar confirmation when Windows requires it.
- WUB does not block Microsoft Defender definition updates according to its publisher.
