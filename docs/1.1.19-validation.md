# Markazi System Checker 1.1.19 validation

## Verified uninstall lifecycle

- Uses `ShellExecuteExW` with a retained process handle instead of returning as soon as the uninstaller launches.
- Waits for the official uninstaller to finish and reads its exit code.
- Polls Windows ARP registration and reports success only after the matching installed-app entry disappears.
- Forces a fresh GetX package scan before the success notification, preventing a stale green `installed` badge.
- Keeps the uninstaller alive on timeout instead of terminating it mid-transaction.

## VLC real-machine cycle

- Initial state: VLC 3.0.23 remained registered under `Program Files (x86)`.
- Uninstall test: registry entry and executable were both removed; package scan returned `is_installed: false`.
- Reinstall source: `H:\PROGRAM\VLC Player\Setup.exe`.
- Reinstall test: silent installation completed, VLC 3.0.21 registered under `C:\Program Files\VideoLAN\VLC`, and package scan returned `is_installed: true`.
- No restart action was requested or accepted.

## UAC behavior

- The Windows launcher manifest already uses `requireAdministrator` with `uiAccess=false`.
- Windows Secure Desktop cannot and must not be auto-confirmed by the application.
- After the user approves the single launch-time UAC prompt, the elevated backend and its child installers do not require repeated UAC confirmation.

## Validation

- Backend regression suite: 72 passed.
- Flutter test suite: 27 passed.
- Flutter static analysis: no issues found.
- Packaged portable smoke test: UI launched and `/api/health` returned version `1.1.19`, phase `4`, API contract `2`.
- Final packaged scan against `H:\PROGRAM` detected the reinstalled VLC 3.0.21 as installed.
