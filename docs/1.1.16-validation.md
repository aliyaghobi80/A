# Markazi System Checker 1.1.16 validation

## Correct Windows uninstallation

- Uninstall always resolves the exact installed application's official registry entry; package setup files are never used as uninstallers.
- Windows Installer entries are identified by `WindowsInstaller` and their registered product code.
- Vendor maintenance commands such as Adobe's `MsiExec.exe /I{product-code}` are normalized to `/x` removal commands.
- MSI removal uses `/passive /norestart REBOOT=ReallySuppress`, showing progress without allowing an automatic reboot.
- Quoted and unquoted EXE uninstaller paths containing spaces are parsed without truncation.
- Non-MSI applications continue to use their vendor-provided `QuietUninstallString` or `UninstallString`.

## Validation

- Real read-only Adobe Acrobat registry resolution: product code detected and invocation normalized to `/x /passive /norestart`.
- Backend regression suite: 66 passed.
- Flutter test suite: 27 passed.
- Flutter static analysis: no issues found.
